# Описание и контекст проекта

Мы разрабатываем имиджевый и информационный корпоративный сайт для Управляющей Компании (УК).
Этот проект создается в том числе для **портфолио разработчика**, поэтому качество исполнения должно быть на уровне **"Awwwards"** (фантастически хорошо, продуманные плавные анимации, идеальная журнальная верстка, внимание к мелочам).

**Референс по дизайну и духу:** sminex.com
- **Дизайн-код:** тонкие шрифты, сдержанность по цветам, много воздуха (пространства), тонкие изящные линии.
- Вдохновляемся референсом, но не копируем его один-в-один.

## Технологический стек
- **Фреймворк:** Nuxt 4 (Vue 3, Composition API, TypeScript).
- **Архитектура:** Только статика (без CMS).
- **Стилизация:** Component-driven CSS (строго без Tailwind). Используем инкапсулированные стили на уровне компонентов (например, Vue `<style scoped>` / CSS Modules / SCSS), избегая глобальных утилитарных библиотек.
- **Дизайн-токены (Единый источник правды)**: СТРОГИЙ ЗАПРЕТ НА ХАРДКОД. Любые значения (px, %, s, цвета #hex/rgba) в CSS, кроме 0 и 100%, должны браться из `var(--название-токена)`. Это касается `font-size`, `padding`, `margin`, `gap`, `transition`, `box-shadow`, `border-radius`, `color`, `background-color` и т.д. Все общие значения строго выносятся в глобальные CSS/SCSS-переменные в выделенные файлы (например, `assets/css/main.css` или `variables.css`). Хардкод цветов и размеров в компонентах ЗАПРЕЩЕН — всё должно переиспользоваться из единого источника.
- **Анимации:** Рекомендуется GSAP / Vue Transitions для премиального уровня взаимодействия (Awwwards).

## Ограничения и особенности
- Контент (новости, список должников, документы) будет обновляться заказчиком напрямую в коде или локальных JSON/Markdown файлах, без админки (CMS не предусмотрена).
- Никаких бэкенд-серверов или баз данных. Все данные зашиты локально на статичном хостинге.

## Структура сайта (согласно ТЗ)

### Главная страница:
1. **Первая секция (Hero):** Видеоролик (предоставляется заказчиком).
2. **Вторая секция ("Наши ЖК"):** Текст и ссылка на отдельную страницу с картой.
3. **Третья секция (Имиджевая):** Большой заголовок, текст, слайдер фоток.
4. **Четвертая секция (Преимущества):** Карточки с цифрами (охват, количество домов и тд). При наведении (hover) - изменение контента (поясняющий текст/картинка).
5. **Пятая секция (Аварийно-диспетчерская служба):** Фокус на работу 24/7. Большой заголовок, текст, слайдер рабочих фотографий.
6. **Шестая секция (Новости):** Справа - карточки новостей. При наведении в левой части экрана динамически подгружается фото и текст. Кнопка "читать целиком".
7. **Седьмая секция (Мы в СМИ):** Журнальная верстка (ассиметричные блоки). Цитаты из статей, ссылка на источник.
8. **Восьмая секция (Должники):** Сухой, информационный список должников (без цели пристыдить).

### Внутренние страницы:
1. **Наши ЖК (Карта):** Карта с метками по регионам (Краснодар, Адыгея, Калининград). При клике на метку меняется медиа и текст по конкретному ЖК. В будущем - 3D модели.
2. **Отдельная новость:** Страница для детального чтения новости (фото, текст).
3. **Документы:** Разделение на общие документы компании и документы конкретных ЖК. Скачивание/просмотр.
